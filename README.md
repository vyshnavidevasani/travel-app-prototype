# Travel App Prototype

## Overview
A mobile app to help solo and women travellers plan safe end-to-end trips with routes, hotels, budget, and optional local guides.

## Screens
- Home
- Place
- Itinerary
- Hotels
- Guides
- Budget

## Tech Stack
- Flutter (recommended) or React Native
- Firebase (Auth, Firestore)
- OpenStreetMap for maps

## Roadmap
- Session 1: Repo setup + first app
- Session 2: Figma prototype
- Session 3: Place page + budget
- Session 4: Map integration
- Session 5: Itinerary builder
- Session 6: Guide profiles
- Session 7: Backend + SOS
- Session 8: Demo build
